### 📍 Active project

**[Gateway Cities Environmental Data Pipeline](https://github.com/jguev/gateway-cities-ej)**
A reproducible pipeline studying lead contamination around the former Exide battery plant in Southeast Los Angeles. It ingests Census, California state, and DTSC ArcGIS data into a layered PostGIS database with privacy enforced by database roles, and produces privacy-safe maps of soil lead across 10,000+ properties.
